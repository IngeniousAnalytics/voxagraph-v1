System Architecture

Our platform employs a sophisticated multi-agent architecture built on LangGraph, orchestrating specialized AI agents that collaborate to transform natural language queries into accurate, validated database operations. This modular design ensures reliability, scalability, and maintainability.

Core Agent Framework

The system consists of five specialized agents, each optimized for specific aspects of the query-to-insight pipeline:

🧠Intent Classification Agent

Analyzes user queries to determine intent and required data sources. Routes requests to appropriate downstream agents and manages clarification workflows for ambiguous queries.

⚙️Query Generation Agent

Transforms natural language into optimized SQL queries. Leverages database schema understanding and maintains context awareness to generate syntactically correct, efficient queries.

✓Validation Agent

Ensures query correctness before execution. Validates syntax, semantic accuracy, and alignment with user intent. Provides quality assurance through automated verification protocols.

▶️Execution Agent

Manages secure query execution with human-in-the-loop oversight. Provides execution previews, cost estimates, and handles result retrieval with comprehensive error management.

📊Visualization Agent

Converts query results into actionable insights through intelligent visualization. Automatically selects optimal chart types and generates interactive, interpretable data representations.

Technical Infrastructure

  • Orchestration Framework: LangGraph provides the foundation for agent coordination, enabling sophisticated multi-step workflows with conditional routing and state management.
  • Database Engine: PostgreSQL serves as the primary data repository, offering enterprise-grade performance, ACID compliance, and support for complex analytical queries.
  • Conversational AI: Advanced language models power natural language understanding and generation across all agents, with model selection optimized for each agent's specific requirements.
  • Visualization Engine: Plotly integration enables creation of interactive, publication-quality visualizations with extensive customization capabilities.
  • Session Management: SQLite-based persistence ensures conversation continuity, enabling users to resume sessions and maintain complete interaction history.

Language Model Evaluation

Extensive comparative analysis informed optimal model selection for each agent:

  • o3-mini (Selected): Demonstrated superior performance with 98%+ accuracy, advanced reasoning capabilities, and excellent instruction following. Optimal balance of accuracy, cost-efficiency, and rate limit considerations.
  • GPT-4o: Exhibited occasional instruction following inconsistencies, resulting in additional validation cycles and extended query generation times.
  • Gemini Flash 2.0: Offered reduced latency but compromised accuracy in query refinement and instruction adherence.
  • Claude Sonnet 3.6: Underperformed due to incomplete parameter specification in tool calls, impacting overall effectiveness.
  • Claude Sonnet 3.7: Demonstrated comparable accuracy to o3-mini with effective tool calling, but higher costs and rate limitations made o3-mini more practical.
  • Deepseek R1: Unsuitable for tool-calling scenarios due to repetitive invocation patterns that degraded system performance.
  • Open Source Alternatives: Comprehensive evaluation confirmed o3-mini's superiority in the accuracy-cost-reliability tradeoff.
